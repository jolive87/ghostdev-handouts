Engineering & IT

What it's built on, how data moves through it, and what it would need from your side.

The whole system in three steps

StepWhat happens
IngestReads the export files the meters already produce. CSV and Excel today; a real 85-column E-Mon D-Mon master file ingested 4,818 of 4,818 rows with zero errors, auto-mapping 13 columns. Modbus / AcquiSuite feeds are the next lane.
BaselinePer meter, per hour of day, per day of week, evaluated in New York local time. Minimum 90 days of history — under that it refuses to analyze rather than guess.
AlertDeviations become events, events become assigned tasks. Detection resolves to the 15-minute interval.

Stack

  • Backend — Python 3.11, FastAPI, SQLAlchemy 2.0 async, asyncpg
  • Database — TimescaleDB (PostgreSQL 16), hypertables for interval data
  • Frontend — React 19, TypeScript, Vite, ECharts
  • Auth — JWT with org scope and roles (Admin / Technician / Viewer)
  • Tests — pytest and Playwright; 600+ backend tests

Security

ControlHow it's enforced
Tenant isolationEvery query is org-scoped. A cross-tenant request returns 404, not a filtered list — the resource simply doesn't exist for you. 38 tests do nothing but try to break it.
Passwords12-character minimum enforced at registration, password change, and admin invite — all three share one policy. bcrypt hashed.
Transport & surfaceCORS locked to known origins. API docs disabled in production, fail-closed. Database TLS certificate verification on.
SecretsEnvironment-based. Never committed to source control.
Local modelsFor the AI layer, models run on your hardware. Company documents never leave the building and never hit a third-party API.

Where it runs

For a pilot it runs on your infrastructure, under your accounts, holding your data. Your data never touches my personal environment, and my source repository never lands on your infrastructure. That's not caution for its own sake — it's the only arrangement that's clean for both sides.

What it needs from you

  • Nothing installed. No agent, no appliance, no change to how meters are read today.
  • One building's meter export files — 90 days' worth.
  • Somebody who can tell us whether a given catch was real.
Known limits — read these

CT/PT ratios are stored but not applied as a multiplier. Dollar figures are computed on raw register values. Deliberate: applying them changes every number in the app.

No AI in the explanations. They're deterministic template text — same inputs, same output, every time, and auditable. A language layer is designed and costed but not shipped, because a model that can invent a number has no business near a bill.

Weather / grid-event correlation is not operational. The collector queries an archive endpoint that lags several days, and buildings aren't geocoded. Treat it as unbuilt.

Three of the six detectors need channels most meters don't report — see the Electrical sheet.
