# ghostdev-handouts

Static handout pages for the Meter Platform demo by Jon Olivencia: a landing page plus three short sheets
for Engineering & IT, Electrical Engineering, and Owners & Investors.

**Live site:** https://jolive87.github.io/ghostdev-handouts/

## Status: archived

This repository is archived. The handouts are now maintained inside Jon's private `Meter_platform`
repository under `demo/handouts`. Make changes there, not here. The GitHub Pages site above stays live
from this archived repository.

## Contents

| File | Page |
| --- | --- |
| `index.html` | Landing page linking to the three sheets |
| `engineering.html` | Engineering & IT |
| `electrical.html` | Electrical Engineering |
| `owners.html` | Owners & Investors |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

Plain HTML with inline CSS; the only external dependency is Google Fonts. To view locally, open
`index.html` in a browser.
